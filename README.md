# Flipkart E-Commerce Product & Pricing Analytics

A data analytics project that explores a real-world Flipkart product catalog to uncover pricing patterns, discount strategy, category concentration, brand distribution, and catalog quality gaps. The project also includes a lightweight bonus machine learning model that predicts a product's category from its product name.

## Project Type

Data Analytics (with a bonus text-classification model)

## Problem Statement

E-commerce marketplaces list thousands of products across many categories and brands. Without structured analysis, it is hard to answer basic business questions such as: Which categories dominate the catalog? How aggressively is each category discounted? Which brands have the largest footprint? Does the "FK Advantage" program price differently than regular listings? This project answers these questions using exploratory data analysis and visualization, and produces a concise set of business insights a marketplace team could act on.

## Dataset

- **Name:** Flipkart E-Commerce Sample Dataset
- **Source:** Kaggle — https://www.kaggle.com/datasets/PromptCloudHQ/flipkart-products
- **Size:** ~20,000 product listings, 15 original columns
- **Key columns used:** `product_name`, `product_category_tree`, `retail_price`, `discounted_price`, `brand`, `product_rating`, `overall_rating`, `is_FK_Advantage_product`, `description`

The dataset is a public product-listing crawl from Flipkart and is not the dataset used in the course masterclass.

## Approach

1. **Data Cleaning**
   - Removed duplicate listings and rows with invalid/missing prices
   - Parsed the nested `product_category_tree` field into a clean `main_category` and `sub_category`
   - Converted "No rating available" text to proper missing values and flagged whether a product has a rating
   - Filled missing brand values with `Unknown` and normalized the `is_FK_Advantage_product` flag
   - Engineered `discount_amount`, `discount_percent`, `description_length`, and `product_name_length`

2. **Exploratory Data Analysis & Visualization**
   - Category distribution (top categories by listing volume)
   - Retail vs discounted price distributions
   - Average discount percentage by category
   - Top brands by listing count
   - Correlation heatmap across price and text-length features
   - Product rating distribution
   - FK Advantage vs regular product discount comparison
   - Most frequent keywords in product names
   - Price spread (boxplot) across top categories

3. **Bonus Predictive Model**
   - TF-IDF vectorization of product names
   - Logistic Regression classifier to predict `main_category` from the product name text
   - Evaluated with accuracy score, classification report, and a confusion matrix

4. **Business Insights**
   - All key findings are summarized in `business_insights.txt`, generated automatically by the script, and included in the project report.

## How to Run

1. Clone this repository
   ```bash
   git clone <repository-url>
   cd My-Data-Analytics-Project
   ```
2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```
3. Download the dataset from the Kaggle link above and place `flipkart_com-ecommerce_sample.csv` in the project root
4. Run the project
   ```bash
   python project.py
   ```
5. Outputs
   - Charts are saved to the `Scrennshots/` folder
   - Business insights are written to `business_insights.txt`
   - A cleaned version of the dataset is saved as `cleaned_flipkart_data.csv`

## Run the dashboard

```bash
streamlit run app.py
```

For Streamlit Cloud, set the main file to `app.py`. Running `project.py` directly remains available for batch output generation.

## Key Business Insights (Summary)

- Clothing and Jewellery together account for a large share of all listings, showing heavy category concentration.
- Average discount varies widely by category — categories like Automotive and Mobiles & Accessories carry noticeably higher average discounts than others.
- FK Advantage products follow a different discount pattern than regular listings, which is useful for evaluating that program's pricing strategy.
- A large proportion of products have no customer rating at all, pointing to a gap in post-purchase review collection.
- Product names carry strong category signal — a simple TF-IDF + Logistic Regression model predicts category with high accuracy, showing this approach could support automated catalog tagging and quality checks.
